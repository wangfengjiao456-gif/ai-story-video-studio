# AI Story Video Studio V3.1

外部 MP3 真实逐句对齐、独立起止时间编辑和 MP4 服务部署，请先阅读 [DEPLOYMENT.md](DEPLOYMENT.md)。仅部署 Vercel 前端不会启动 FFmpeg；未通过真实服务连接检查时导出按钮禁用。

中文界面的故事视频创作工作台，使用 React + Vite；V1 功能无需付费 API，V2 的 ElevenLabs 配音通过 Vercel 服务端调用。桌面为左侧导航、中央编辑、右侧预览布局；iPad 与手机会自动适配。

## 运行

需要 Node.js 20.19+ 或 22.12+（推荐 Node.js 24）。

```bash
npm install
npm run dev
```

打开终端显示的地址（默认 http://localhost:5173）。同一局域网 iPad 可访问电脑 IP 的 5173 端口；需允许本地防火墙访问。

```bash
npm test
npm run build
npm run preview
```

构建产物在 `dist/`。V1 可以纯静态运行，V2 配音需要同时运行根目录 `api/` 中的 Vercel Function。`npm run preview` 默认端口 4173。

## 已实现

- 英文文章、中文译文编辑、清空、手动保存；按句序拆分，允许仅英文或仅中文。
- 分镜英文、中文、画面描述编辑；添加、删除、上移、下移，1–60 秒时长设置，最多 500 镜。
- 固定人物名称、外貌、服装；四种画风设置与 9:16 / 16:9 比例。
- 系统英文语音选择、0.5–1.5 倍速、逐句试听与停止；英文、中文和双语字幕。
- 按时长播放演示分镜、暂停（再次播放从当前分镜重新计时）、前后切换与时间线。
- JSON 下载、格式校验导入、当前浏览器 localStorage 保存与恢复。

首次加载提供示例。保存为手动操作；刷新前请点击“保存项目”。导入覆盖工作区前会确认，导入后需保存。不同设备和浏览器不共享存档；隐私浏览或清理缓存可能丢失数据，推荐定期导出 JSON。

## 操作流程

1. 输入英文与对应中文；每句英文对应一句中文。
2. 点击自动拆分，检查句序；已有分镜会在确认后替换。
3. 在故事分镜中补充画面描述并调整顺序、时长。
4. 设置人物和画风，选择字幕与语速，逐句试听。
5. 右侧播放预览，保存并导出 JSON 备份。

## 真实能力与限制

- **画面均为 CSS 演示占位，并非 AI 生成。**画风设置保存在项目中，当前演示图形不会根据描述生成人物或图片。
- **MP4 导出待开发**，界面仅显示状态，没有无效导出按钮。
- 不提供自动翻译、音频云存储或用户账号。V3.1 新增 OpenAI 配图调用代码，真实生成尚待 Key 验证。V2 支持 ElevenLabs 生成和 MP3 下载，音频只存当前页面内存。
- V1 无音频预览按分镜时长播放字幕，不自动朗读；V2 音频播放按播放器时间更新字幕。逐句朗读需点击触发，适配 Safari 的用户手势限制。系统声音取决于设备配置，可能需要联网；未支持语音合成时可继续编辑。
- 分句依赖 `Intl.Segmenter`，旧浏览器使用标点回退；缩写可能导致误拆，需人工检查。
- 未承诺在实体 iPad Safari 验证：需在目标设备检查语音、JSON 下载与文件导入。

## 手工验收

- 输入两句英文、一句中文，拆分后第二镜中文应为空；中文多于英文时不丢失中文。
- 修改、重排、删除分镜，预览内容与列表一致；空列表不能播放。
- 保存后刷新，内容恢复；导出再导入，人物、时长、比例与字幕保持一致。
- 导入无效或大于 5 MB 的文件，应报错且保留现有工作区。
- 调整语速、字幕、比例；逐句试听与停止；iPad 横竖屏无横向页面溢出。

## 文本限制与存档恢复

项目名称最多 120 个字符，其余所有可编辑文本（英文文章、中文译文、分镜英文/中文/画面描述、人物名称/外貌/服装）每项最多 100,000 个字符。字符按 JavaScript UTF-16 长度计数，部分表情占两个单位。编辑时不会静默截断粘贴内容；超限字段标红，保存或正常导出前会显示中文原因并停止操作，当前草稿保留供缩短修复。

本地保存、刷新恢复、JSON 导入与导出共用项目校验。项目 JSON 的 UTF-8 总大小不得超过 5 MB，导出和本地保存使用相同的紧凑格式。保存内容只包含 V1 项目字段，分镜 ID 为编辑器内部标识，恢复和导入时重新生成。浏览器存储配额可能小于项目大小上限，配额或权限失败会明确显示“保存失败”，此时可将有效草稿导出为 JSON。

对于旧版本留下的无效存档：

- 仅文本超限且结构有效时，完整载入原文供修复，显示持续恢复提示；不会截断原文。
- JSON 损坏或结构不合法时，显示恢复界面并禁用正常保存和导出；不会自动用示例替换，可下载原始存档并导入有效 JSON 继续工作。
- 保存修复后的项目或导入的有效项目时，先将无效旧存档原文保留至独立恢复备份，再写入新项目；备份失败则禁止覆盖。
- 恢复备份在界面持续提供下载入口，刷新后仍可下载。原始恢复文件保留的是未修复数据，需修复后才能正常导入。
- 本地存储使用 `story-studio-v1` 保存项目、`story-studio-v1.recovery` 保存原始恢复备份；不要清理浏览器数据直至已下载备份。

自动化回归测试覆盖所有文本字段的边界与超限、配额/权限失败、刷新恢复、损坏存档保护、备份失败和 JSON 实际下载后重新导入。

## V2 ElevenLabs 配音

### 固定配置与官方核实

- Voice ID：`NDTYOmYEjbDIVCKB35i3`（未获取账户声音列表，显示真实 ID，不虚构名称）。
- 模型固定 `eleven_v3` / Eleven v3，语言 `en` / English。
- 通过 `voice_settings.speed` 设置生成速度，默认 **0.8**；页面提供 **0.7–1.2** 的慢速跟读常用范围。
- 每次上限 5,000 字符。文章超过上限仍可用 V1 编辑保存，请缩短文章或逐个分镜生成；不偷偷换模型、截断、分段计费或自动重试。
- 输出 `mp3_44100_128`。50 秒上游超时，函数最大 60 秒；响应限制 4 MB，超过时提示缩短文章或按分镜生成。生成失败或超时仍可能产生上游费用，请先检查账户历史再重新生成。

2026-11-03 核实的官方来源：

- [模型与单次字符上限](https://elevenlabs.io/docs/overview/models)：支持 `eleven_v3`。
- [官方语速说明](https://elevenlabs.io/docs/overview/capabilities/text-to-speech/best-practices)：`voice_settings` 可设置 0.7–1.2；[官方维护的语音参数参考](https://github.com/elevenlabs/skills/blob/main/text-to-speech/references/voice-settings.md) 标明 v3 支持 speed、REST 支持更宽范围。本项目采用两者共同覆盖的范围，0.8 无需替换模型。
- [生成音频与字符时间戳](https://elevenlabs.io/docs/api-reference/text-to-speech/convert-with-timestamps)：使用 `/v1/text-to-speech/{voice_id}/with-timestamps`，请求 `language_code: en`。

会员身份本身不证明此 Voice ID 对当前 Key 可用；真实音色、账号权限及模型的实际慢速效果，需要配置真实 Key 后试听确认。如果 API 拒绝设置，会显示错误，不回退到其他模型。

### 使用方式与同步边界

1. 完成文章、双语分镜，打开左侧 **AI 配音**。
2. 选择 AI 生成语速，点击整篇或对应分镜的生成按钮；每次生成可能消耗额度。
3. 生成后手动点击试听，使用原生播放器暂停、继续和拖动；从头播放会重置到起点。所有镜都已生成时可顺序播放分镜音频。
4. 整篇音频使用浏览器读取的真实 MP3 时长；当 API 字符数组与原文对应、时间合法且与时长一致时，标记 **API 字符时间戳同步**。该标签表示数据来源，不保证模型对齐误差为零，需试听校对。
5. 缺少/异常时间戳，或分镜英文不能对应文章时，明确标记 **估算同步**：按英文词数权重分配真实音频总时长。无真实时长时不伪造同步。
6. 单镜音频按真实时长显示、按音频 `ended` 事件切镜。播放器 `currentTime` 驱动预览，暂停保持进度，双语字幕沿用分镜内容；不声称实现中文逐词对齐。
7. 编辑英文或更改生成语速时，相关音频标记 **需要重新生成**；旧文件仍可下载。文章音频和分镜音频分别绑定各自的英文。中文、画面描述等修改不会要求重新合成英文声音。
8. 手动下载 MP3。音频、Blob URL 与 AI 生成速度仅在当前会话内，不写入项目 JSON/localStorage，也没有云端音频存储；刷新或导入项目后需重新生成。V1 JSON 结构及旧项目不变。

### Vercel 环境变量（由项目所有者操作）

## V3 绘本画面与字幕模板

在 V2 代码基础上新增展示层，未修改 ElevenLabs 服务端、Voice ID、模型、默认语速、音频客户端或播放 Hook。保留原有三栏结构与奶油白/深绿色风格；V2 尚未合并 main 时，V3 PR 以 `feat/elevenlabs-v2` 为基线，V2 合并后再由维护者调整 PR 基线。

### 模板和操作

- 打开“配音与字幕”→“视频画面模板”。A 为上图下字幕，默认图片约 72%、独立奶油白字幕区 28%；B 为全屏图与底部柔和渐变遮罩。点击模板恢复其默认样式并切到 9:16，保留原文字、图片和已生成音频。
- 可调整英文/中文字号、各自行距、中英文间距、区域高度、底部位置、背景/遮罩不透明度、颜色、左对齐/居中和三种字幕显示模式。一键恢复只重置当前模板样式，不删除内容。
- 字号以 1080p 最终画面为单位，整个画面等比缩放到各设备预览尺寸；横屏保留兼容布局，V3 两种模板以 9:16 为主要验收对象。
- 英文 40–80px、中文 30–64px，行距 1.2–1.8，字幕区 25%–40%，底部安全边距 6%–12%，不透明度 85%–100%。不透明度下限和自动颜色保护用于确保复杂背景下的可读性，低对比度选择会显示提示并在预览中替换为可读颜色。
- 长句先自动减小到可读字号，仍放不下时自动分页，每页显示在固定安全区域内；不使用省略号或隐藏溢出截断文本。可手动逐页检查，所有英文和中文内容都保留。超长内容可能有很多页，适合拆成更多分镜后跟读。
- 字幕分镜沿用 V2 的 API 时间戳/估算时间线；**同一镜内的长句翻页按本镜时长比例估算**，不是新的逐词 API 对齐。暂停保留当前页，拖动音频后更新页；字体/模板变化不会发起生成请求。
- “字幕安全区域”仅叠加编辑器辅助线，独立于画面内容元素；偏好可以保存进 JSON，但辅助线不是视频内容。本阶段仍无最终 MP4/图片导出，不能声称已验证完整导出流水线。

### 每镜图片

“故事分镜”中新增本镜图片上传、移除、Cover/Contain、缩放和横纵裁切焦点。所有展示均等比，不提供 Fill 拉伸。图片与分镜绑定，排序和模板切换不会丢失，未上传时沿用绘本占位画面并明确标注非 AI 生成。画面描述与提示词保留，V4 图片生成仅留接口说明，本次没有生成图片服务。

只接受带合法文件头的 JPG/PNG/WebP，拒绝 SVG、GIF 和远程 URL。上传上限 8 MB、1,600 万像素，画布重新编码为最长边 1440px、600 KB 内的 JPEG，去除原始文件附加信息；透明背景铺奶油白。图片内嵌保存于每镜 `imageRef`，便于 JSON 移动项目。全项目仍限 5 MB，浏览器配额更小时会报保存失败，保留草稿与旧存档；请导出 JSON 备份并减少图片大小/数量。

配置字段为项目级 `videoTemplate`、`subtitleStyle`、`subtitlePosition`、`subtitleSafeArea`；每镜 `imageFit`、`imagePosition`、`imageScale`、`imageRef`。V1/V2 JSON 缺字段时自动补默认值，版本号仍为 1 以保持现有内容协议。V3 JSON 的新配置需 V3 网站才能完整恢复，旧版本网站不会渲染 V3 设置。保存仅投影已支持字段，不含 API Key 或音频 Blob；V2 的音频仍在内存，刷新/导入后需重新生成，下载的 MP3 不受影响。

### 连续预览 → 真实 MP4

左侧新增“视频预览与导出”，原文章、分镜、上传图片、单镜预览与配音页面保留。

1. 使用自己的文章及分镜，每镜先有图片。选择当前整篇 ElevenLabs MP3 或全部逐镜 MP3；也可导入此前下载的整篇 MP3，在 Key 未覆盖当前分支时继续制作。导入文件来源和实际语速需人工确认。
2. 点击“准备完整视频”，读取真实 MP3 metadata 时长；网站生成的整篇音频优先用可验证 API 字符对齐，没有对齐则标明词数估算；外部上传 MP3 必须先完成强制对齐或手动确认全部起止时间。逐镜按各 MP3 真实时长连续安排。
3. 完整预览从第 1 镜连续至最后，支持暂停、继续、重播与全局进度拖动。画面使用固定 9:16 / 1080×1920，可能与原编辑预览的其他画幅不同。
4. 时间轴量化到 30fps；整镜字幕边界与长字幕页共用一份帧时间轴，导出逐页烘焙同一画布，避免预览与视频另算时间。长字幕页内翻页仍是比例估算，不冒充 API 对齐。
5. “手动微调字幕切镜时间”可分别修改每镜开始与结束时间，允许句间静音并在静音隐藏字幕，保存进项目 `videoTiming`。更改文本、音频或生成语速后会拒用过期音频/旧时轴；JSON 不保存 MP3，本地页面刷新后需重新生成或导入音频。
6. 点击“导出真实 MP4”，PNG 与 MP3 直接上传到独立渲染服务，显示上传/FFmpeg 进度；失败显示原因，取消不会删除项目。完成后提供原生视频播放器和下载，支持 Range 拖动与 iPad 分享到文件。

导出开始后是固定项目/音频快照；继续编辑不会修改正在导出的任务，新修改需要重新导出。图片或 MP3 缺失、过期、无法读取真实时长、超过任务限制时拒绝导出，不生成静音假视频。MP4 结果保留约一小时，需及时下载。

### 必需部署架构

真实 MP4 使用独立长运行 FFmpeg 容器，不强塞进 Vercel Functions，也不依赖 iPad 的 wasm 编码能力。部署步骤、鉴权、CORS、资源与限制见 [renderer/README.md](renderer/README.md)。**只部署 Vercel 前端不能启用 MP4**；必须另外部署 worker，并在当前 Preview 设置服务器端 `RENDERER_URL` 和 `RENDERER_API_KEY`，worker 设置同一密钥及 `ALLOWED_ORIGINS` 精确允许当前 Preview 来源。现有 ELEVENLABS_API_KEY、OPENAI_API_KEY 的 Preview 分支范围也需要所有者检查。未部署时明确显示“MP4 渲染服务尚未部署”，不能说线上导出已经可用。

Production 未更改。先用 Preview、真实 MP3 和图片验证部署；未经用户确认不发起收费调用。独立服务只接收渲染媒体，不接收 AI 密钥。
